# Бот «Расписание колледжа»

Бот показывает расписание из Excel через удобное меню:

1. постоянная нижняя кнопка **«Открыть расписание»**;
2. выбор курса;
3. выбор группы;
4. выбор дня или кнопка **«Вся неделя»**.

После `/start` бот сохраняет подписку пользователя и присылает уведомление,
когда загружено новое расписание. Команда `/stop` отключает уведомления.

В проект импортированы две группы второго курса:

- `П9/25-4`;
- `Э9/25-3`.

Текущее расписание содержит занятия на 20 и 21 ноября 2026 года.

## Запуск в Visual Studio Code

Откройте эту папку в VS Code, затем выберите **Terminal → New Terminal** и выполните:

```powershell
& 'C:\Users\avoka\AppData\Local\Python\bin\python.exe' bot.py
```

Токен уже хранится локально в `.env`. Не отправляйте этот файл другим людям и не добавляйте его в Git. Для остановки бота нажмите `Ctrl+C`.

## Обновление расписания

Замените файл `data/schedule.xlsx` новой таблицей такого же формата. Затем установите библиотеку для чтения Excel и повторно создайте данные:

```powershell
& 'C:\Users\avoka\AppData\Local\Python\bin\python.exe' -m pip install -r requirements-import.txt
& 'C:\Users\avoka\AppData\Local\Python\bin\python.exe' import_schedule.py
```

После этого перезапустите `bot.py`. В Railway база подписчиков хранится на
постоянном томе, подключённом как `/data`.

## Автоматическое обновление

Для фоновой проверки личного кабинета задайте в Railway переменные
`CABINET_LOGIN_URL`, `CABINET_DASHBOARD_URL`, `CABINET_USERNAME`,
`CABINET_PASSWORD`, `CABINET_USERNAME_FIELD=login` и
`CABINET_PASSWORD_FIELD=password`. Время проверок задаётся переменной
`CHECK_TIMES_MSK` в формате `07:00,11:00,15:00,18:00,21:00,23:00`.
`CABINET_SCHEDULE_URL` можно не задавать: бот попробует найти ссылку Excel
по меню кабинета автоматически.

Бот проверяет Excel по Москве в 07:00, 11:00, 15:00, 18:00, 21:00 и 23:00.
Если изменилось расписание групп
`П9/25-4` или `Э9/25-3`, новая версия сохраняется на постоянный том,
меню обновляется без ручного перезапуска, а всем подписчикам отправляется
уведомление. Если изменений нет, после каждой запланированной проверки бот
также присылает статус, что расписание осталось прежним. Импортируется только очная форма; листы с пометками `ДОТ`,
`дистанционная`, `заочная` или `очно-заочная` игнорируются. Изменения в других
группах и формах обучения рассылку не запускают.

## Пользователи бота

На постоянном томе Railway хранится база пользователей: Telegram ID, имя,
`@username`, дата последней активности, статус подписки и последняя выбранная
группа. После задания переменной Railway `ADMIN_TELEGRAM_IDS` (через запятую)
администратор может отправить боту `/users` и увидеть список активных
пользователей. Команда `/myid` покажет собственный Telegram ID для настройки
этой переменной.
